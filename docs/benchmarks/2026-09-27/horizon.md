### horizon

**Hypothesis.** If this game rewards a faster decision loop, the same policy should do measurably better as its answers arrive sooner — which is the gain a faster model would bring, measured before that model exists. If it does not, cadence is not the bottleneck and a faster model will not help here by speed alone.
**Deciding metric.** Deaths per minute and kills per minute of the same policy across injected answer latencies (0 ms is a local policy; 200–250 ms is today's measured Jev round trip; 600 ms a slow remote model).
