- Confirmatory (two-sided): in weak-legs, plasticity-active minus organism differs from zero in energy taken in (fedJ) and in feeding bouts (meals). The decision rule, not the sign, decides what is claimed.

- Boundary: where the plasticity never becomes cautious (unimpaired, mild impairment, asymmetric gait) it cannot act, so plasticity-active should equal the organism exactly there.
- Stated before any run of this protocol: given the 2026-11-07 held-out study, the expected outcome is NO_DEMONSTRATED_IMPROVEMENT or INCONCLUSIVE. The protocol is built to measure that accurately, not to overturn it.

## Limits

- Simulated research flies in one yard. A result here is a statement about these controllers in this simulator, not about real flies or about Eva or ECHO.
- Behavioural records reproduce byte for byte only on the platform they were made on (platform `Math` differs elsewhere); the verifier says when it cannot replay.
- Compute numbers are one machine's, under concurrent shards; they do not transfer to other hardware.
- Stopping rule: Every unit of a split runs once. The held-out split runs once, from a clean commit, after the dev split's records are committed; no interim look, no rerun, no replacement of a failed run. A failed or inconclusive held-out result stays in the record.
- No benchmark result promotes a controller to either original: that needs a separate owner decision and a continuity validation (docs/ECHO_INTELLIGENCE_METROLOGY.md).

node scripts/run-ts.mjs scripts/echo-metrology.ts verify --protocol plasticity-locomotor-v1 --split dev --replay 6
node scripts/run-ts.mjs scripts/echo-metrology.ts run --protocol plasticity-locomotor-v1 --split dev --shard 0/1 --out records.local.jsonl
