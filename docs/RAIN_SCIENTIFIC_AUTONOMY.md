## Run and inspect

Load the local Qwen model with sufficient context (the study uses 16,384 tokens and one
inference slot). This does not require a second model, cloud credentials or network papers.

```bash
bun run rain:inception:study prepare --root .rain-research/my-live-study
# Review the printed charter, budgets, model and complete digest first.
bun run rain:inception:study run --root .rain-research/my-live-study --authorize FULL_DIGEST --operator Your.Operator.Role
bun run rain:inception:study inspect --root .rain-research/my-live-study
```

Limits: two experiments, four design iterations, three matched seed pairs, at most 80
pedestrians, 60 model calls, 250,000 reported tokens, 90 minutes, and 64 MiB storage.
Each call has a ten-minute deadline. Completion requires an evidence-linked withheld-seed
confirmation and a manuscript reviewed by a separate model call. No fixture fallback,
silent response repair, automatic retry, publishing or descendant execution occurs.
Ctrl+C requests cooperative emergency stop in the running terminal. `inspect` never
resumes inference and independently replays retained records. Reusing a started study
root for execution is refused; new work requires another explicit reviewed invocation.
For general pause/resume and scheduler controls use the existing native operator service.

`inspect` reports `live_cycle_complete` from recorded milestones and exact model identity,
including equal pre-review contexts for the two evidence interpreters. This is a workflow
check, not a judgment of source relevance, originality or scientific correctness. Both
research roles and critics may use the same Qwen weights. Human scientific review remains
necessary even if all milestone checks pass. Native manuscripts, failures, proposal
specifications and evidence are retained under the study root.

The designer can now return zero candidates with an `untestable` object containing a
reason, missing capabilities and a proposed simulator-extension specification. The host
retains this and stops without execution. Empty unexplained or contradictory responses
are rejected. Extension text cannot execute code or authorize a new simulator.

## Approved sources and cognitive artifacts

List the pinned author-supplied corpus with `bun run rain:inception:source catalog`.
Its document hashes and commit are inspectable. Approved corpus IDs attached to
`profile.source_ids` now resolve independently of lexical search ranking. Catalogue
presence is not independent validation; an unavailable paper or artwork is not invented.

Import only an explicitly supplied UTF-8 text file:

```bash
bun run rain:inception:source prepare --file supplied.txt --root .rain-research/my-lab --collection my-work --title "Supplied work" --creator "Operator-provided attribution" --category paper
# Inspect the exact excerpt and manifest, then repeat with import and approval:
bun run rain:inception:source import --file supplied.txt --root .rain-research/my-lab --collection my-work --title "Supplied work" --creator "Operator-provided attribution" --category paper --approve MANIFEST_SHA256 --operator Your.Operator.Role
```

The pipeline hashes the complete document (maximum one MiB), retains a bounded excerpt
(maximum 4,000 UTF-16 code units), its hash and range, attribution, category, version,
consent and previous manifest digest. Revisions use `--version` and `--previous`; stale
or substituted revisions fail. It never scans personal directories or imports private
conversations. PDF parsing is not implemented; supply an approved text extraction.
Categories also include engineering, poetry, music-description, art-description,
philosophy and approved-discussion. Creator attribution remains operator supplied.
Attach the resulting source ID to a new reviewed profile; importing alone changes no charter.

Opt into structured cognitive artifacts with `profile.strategy_version: 1`, or use
`--strategies v1` consistently in the study's prepare and run commands. The six strategies
produce explicit proposals, assumptions, observables, falsification criteria, limitations,
testability classifications and earlier-decision references. Reflection comparisons require
both an available earlier prediction and verified evidence references. Artistic ideas are
design proposals, not evidence or inferred personal preferences. Missing-capability and
not-applicable outcomes are allowed. Strategy evaluation counts artifacts and referenced
comparisons; it does not claim those comparisons are correct or that the model reproduces
Christopher's mind. The final opt-in strategy protocol has deterministic tests; a completed
live validation of all six strategies remains outstanding.

The existing journals, source manifests, memory namespaces, epochs, forgetting controls,
