# Project ECHO verification

Project ECHO is an opt-in extension of the actual Bethesda fly controller.
The baseline remains the default. Use `/?echo=1` before entering Bethesda,
then open **Fly → Self-Model**. See [architecture](PROJECT_ECHO.md) and
[study results](PROJECT_ECHO_RESULTS.md).

No existing tests or verification thresholds were removed or weakened. Initial
checks exposed stale versioned pilot/calibration data, a timeout under concurrent
load, and a wrapper-argument bug in the headless smoke CLI. Generated data were
recomputed, the CLI was repaired, and the affected checks passed on recheck.

The panel test intentionally disables WebGL, asserts the visible fallback, and
excludes only the exact renderer error caused by that injected fault from the
unexpected-error count. The panel remains useful and its simulation clock
continues without a GPU.

Canonical scenes contain animation: the captures are not byte-identical.
Reported pixel changes were 0.3–9%, with stable scene exposure and small
visibility-dependent draw-count changes. A reused software-renderer session
stalled and produced an incomplete capture; all nine final after-images were
captured in fresh browser instances using the existing canonical shot definitions.
No geometry, material, lighting, anatomy or pose sources were changed for ECHO.

## Reproduce

```sh
npm run build
npm run lint
npm run format:check
npm run test:run -- --maxWorkers=2
npm run bethesda:life:smoke
npm run bethesda:echo:smoke
npm run rain:echo:verify
npm run rain:fly:verify
npm run rain:fly -- --pilot --check
npm run verify:echo
```

Browser checks require a Puppeteer-compatible Chrome installation; set
`PUPPETEER_EXECUTABLE_PATH` when using a separately installed browser.

The main study ran from clean commit
`a71066264ba3ff3a6949316bdc0f0bcee92c5520`, before its outcomes were inspected.
The calibration report was generated from clean commit
`67ce0f015f0bea674a3783f379b185e647e30acc`. The self-model configuration,
apparatus and acceptance criteria were not changed after the held-out evaluation.

## Interpretation

The held-out study supports movement compensation and causal attribution in
this reduced-order apparatus. Retained learning **did not** improve early
re-exposure regulation; ECHO-03 is a retained negative result. Ablations do
not establish additional benefit from episodic memory or uncertainty over
simpler adaptive configurations. The experiment records include uncertainty,
per-trial failures, actual intervention conditions and exact replay hashes.

Local odometry is idealized. Compensation is validated here only for kinematic
walking, not biological motor control or the separate MuJoCo backend. A
self-model checkpoint cannot restore a complete fly or establish durable shared
continuity. These mechanisms do not establish subjective consciousness.
