# R.A.I.N. research intelligence: engineering and experimental report

Date: 2026-11-13. Target: `topherchris420/lop-nur-twin`, the active R.A.I.N. Lab.

The implementation adds source-bound local CPU campaigns, explicit rival-model
selection, independent-seed falsification, an advisory four-perspective model
panel, and an interactive evidence observatory to the existing Lab. It preserves
the native journal, registry, identities, simulator authority and learning gates.
It is a bounded engineering increment, not a claim that the complete autonomous
scientific institution described in the mission has been achieved.

The controlled pilot passed its frozen criterion: at 192 declared work units,
information-based selection falsified one incorrect claim in both panels; FIFO
falsified none. An additional validation campaign exposed a second incorrect
claim. All 12 completed panels reproduced their numerical results and exact
recorded provenance in a separate replay. General improvement over the previous
R.A.I.N. architecture, novel autonomous discovery, and live-model scientific
reasoning remain unproven.

## Investigation and priorities

The current Lab already implements local inference adapters, James/Jasmine/Elena/
Luca perspectives, native protocol compilation, preregistration, a registry,
matched simulation arms, replay, research knowledge views, source context,
manuscripts, session locks, and evaluated procedural learning with human
activation. Rebuilding these mechanisms would add migration risk. Existing agent
SOUL files, accumulated memories, original research records and model history
were not overwritten.

The highest-value gaps addressed here were a missing execution bridge to the
scientific validation projects and a priority rule that did not explicitly price
discrimination between probabilistic rivals. The new path reuses `ResearchStore`
and `Registry`; research-domain modules still cannot spawn processes, access the
network, write files directly, or mutate the city simulator.

## Implemented mechanisms

See [architecture and authority](ARCHITECTURE.md) and [operator usage](USAGE.md).

| Mechanism                          | Concrete behavior and scientific purpose                                                                                                                                                                                                              |
| ---------------------------------- | ----------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| Frozen research contract           | Closed schemas bind rivals, predictions, adapter parameters, correctness threshold, falsifier, panel sizes, seeds, error allocation and resource limits before measurement. Unknown executable/code fields fail.                                      |
| Conditional information scheduling | Computes exact mutual information for one binary seed-level observation per declared work unit. Updates rival weights using log likelihoods; an outcome impossible under every rival rejects the supplied model set.                                  |
| Independent-seed replication       | Disjoint screen/confirmation blocks per design; both favorable and negative findings receive confirmation. Globally exposed/reserved panels cannot be relabeled as new holdouts in later campaigns.                                                   |

| Failure accounting                 | Reserve before work; failed/interrupted work retains its cost. Explicit reviewed lock recovery and continuation; an interrupted reserved panel cannot be rerun as fresh confirmation. Unknown interrupted runtime stays unknown.                      |
| Attributable collaboration         | Four separate optional calls use existing SOUL roles and critique earlier contributions. Typed recommendations may select existing design IDs; they cannot change frozen rules or authorize execution. Scripted structural checks are labeled.        |
| Read-only instrumentation          | Offline searchable/filterable semantic tables expose hypotheses, progress, costs, uncertainty, reviews, failures, conditional model beliefs and event hashes. `/analysis` links to the generated observatory. This is a snapshot, not live telemetry. |

Original contributions relative to the inspected reference include rejecting an
exhausted rival-model set rather than manufacturing posterior certainty;
whole-journal seed exposure protection; replication of falsification itself;
conservative reservations for interrupted panels; and rederivation of claims
from raw samples before context reaches an advisory panel. These are specific
engineering choices. Their existence is not evidence of global novelty or
superiority to unobserved Autolab capabilities.

## Controlled experiment

The source, frozen plans and decision rule were committed and pushed as
[`5d96a3e`](https://github.com/topherchris420/lop-nur-twin/commit/5d96a3e0a93e2dc8e7cdc40a264f0a74b6d1d2d4)
before measurement. The producer recorded a clean working tree. Each campaign
declared four designs, 64 screening sessions and 128 confirmation sessions per
measured design, a 0.75 minimum correct-session probability, family alpha 0.05,
and a 120-second panel timeout. Each endpoint receives alpha 0.00625 across eight
declared endpoints, including unused allocations. This is not a pooled 95%
guarantee across all three campaigns. The unit of observation is an independently
seeded simulated session, not an individual correlated batch or signal sample.

QNP work costs one unit per session; DRR costs four. Those are frozen accounting
weights, not measured CPU-seconds, dollars or energy. CPU wall time is separately
recorded. Information predictions were supplied by the plan and intentionally
encode the known repeated-testing concern. They were not discovered by a model.

| Arm             | Budget/completed units | Selected work                | Claims falsified in both panels | Worker wall time |
| --------------- | ---------------------: | ---------------------------- | ------------------------------: | ---------------: |
| FIFO            |                    192 | QNP sequential null          |                               0 |          11.13 s |
| Information     |                    192 | QNP repeated fixed-test null |                               1 |          10.51 s |
| Full validation |                  1,920 | All four designs             |                               2 |          42.78 s |

The equal-budget arms terminate `budget_exhausted`, with other designs unmeasured;
that is expected behavior. The full-validation arm completes. The primary
criterion was the number of predeclared incorrect claims falsified in **both**
panels at 192 units, with information required to exceed FIFO. It passed, 1 > 0.
There is no meaningful speed claim from these single wall-time measurements.

The FIFO arm is a matched ablation on the **new CPU backend**. It is not an
end-to-end execution of the old Lab or evidence that the old Lab would choose a
naive test. One benchmark with supplied predictive models does not establish
population-level scheduler superiority. A larger independently designed,
multi-instance study, including misspecified rivals and selection overhead, is
required before promotion as a generally better strategy.

### Measured scientific conclusions

Full-validation counts and simultaneous per-endpoint intervals are shown below.
All listed independent numerical controls passed.

| Claim: at least 75% correct sessions                                                | Screening / 64 | Confirmation / 128 | Confirmation interval | Campaign conclusion                                        |
| ----------------------------------------------------------------------------------- | -------------: | -----------------: | --------------------- | ---------------------------------------------------------- |
| QNP sequential detector stays quiet under the binomial null                         |             64 |                128 | [0.84989, 1]          | Criterion supported in both panels                         |
| Repeated unadjusted fixed tests stay quiet under the same null                      |             13 |                 19 | [0, 0.29855]          | Falsified in both panels                                   |
| DRR permutation surrogates find no edge on independent autocorrelated null channels |             11 |                 18 | [0, 0.29073]          | Falsified in both panels                                   |
| DRR circular surrogates find no edge in that regime                                 |             59 |                123 | [0.81083, 1]          | Withheld: screening interval [0.70959, 1] was inconclusive |

The information arm independently obtained 10/64 and 17/128 quiet fixed-test
sessions, with confirmation upper bound 0.28292. The separately computed exact
false-alarm probability of that repeated fixed rule is approximately 0.84728543
under the declared binomial model, consistent with the observed poor session
specificity. QNP checks also include independently calculated one-batch
likelihood-ratio mixture agreement, zero-error negative control, and an
overwhelming positive control.

The DRR probe uses three independent stationary Gaussian AR(1) channels,
coefficient 0.9, length 256, maximum lag 4, 49 surrogates, alpha 0.05 and a
max-statistic correction. Permutation discards temporal dependence. The result
demonstrates failure of the tested permutation configuration under this null;
it does not invalidate all DRR configurations. Circular shifts did substantially
better on this sample, but the frozen two-panel rule correctly withheld support.
The upstream longer 512-sample/99-surrogate regime was not measured here.

A 75% correctness threshold is a modest diagnostic criterion. It does not
establish nominal 5% false-alarm control. Null specificity is not discovery power.
All observations are computational simulations; no physical quantum device,
causal biological system or empirical dataset was measured.

## Remaining boundaries and next evidence needed

There is no arbitrary generated-code execution, distributed/cloud scheduler,
automatic self-modification, live observatory streaming, or new adapter for TRIAD
or Waveform Shift Quantum. The optional panel can propose testable narratives
within existing templates, but no original model-generated discovery was measured.
The existing evaluated-guidance approval route is preserved; this study does not
show long-term improvement of research methodology or model weights.

The worker executes explicitly trusted local source. It is not hostile-code
isolation, descendant-process containment or a total memory limit. The interpreter
executable and package versions are bound; complete DLL/wheel contents are not
sealed. Hash chains are consistency mechanisms, not signatures or protection
against an actor replacing the entire archive. Local review acknowledgement does
not authenticate human identity. Offline exports should be treated as context,
not authority, until verified against preserved originals.

The next defensible experiments are independently authored scheduler instances
with misspecified predictions; power/calibration sweeps including known positive
systems; an independent statistical implementation; and a live local-model panel
evaluated on preregistered proposal quality and useful follow-up experiments.
These require fresh seed blocks and frozen criteria. No result here authorizes
merging, deployment, paid compute or automatic activation of a methodology.

Rollback is a revert of the feature commits. Preserve the producing revision and
the original archive for replay; retain all original native journals and memories.
