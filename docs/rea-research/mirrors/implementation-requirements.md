# Original Research Learning Engine requirements

1. Derive recurring procedural errors from retained validation/failure journals with evidence references. Valid negative outcomes are excluded.
2. Keep proposal, independent evaluation and operator activation as separate immutable records. Context rules bind domain/backend/stage/error; guidance never changes evaluation criteria.
3. Freeze task split, scoring rules and resource budgets before outcomes. Holdout IDs must be disjoint from proposal evidence; report paired effects, sample sizes and uncertainty.
4. Activate only independently evaluated beneficial versions with digest-bound operator attestation. Rollback records a new event; prior versions remain inspectable.
5. Tests must reject contaminated evaluation, post-outcome rule changes, unapproved activation, mismatched scope and corrupted records. Demonstrate recurring error → proposal → unchanged baseline comparison → recorded result.
