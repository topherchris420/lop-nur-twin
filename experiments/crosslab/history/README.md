# Cross-lab study record

This directory preserves selected records from the original CIRCLE–TRIAD experiment and its first heavy-motion follow-up. The archived work originated in `james_library`; Lop Nur Twin is the active lab. The JSON retains the original registration, measurements, negative or inconclusive outcomes, and SHA-256 digests of the two complete archives and the selected source records.

- The first run was inconclusive. Heavy-motion coverage was 31/160, below the registered 25% minimum.
- The follow-up found that a relaxed gate cleared its descriptive screen on two pulse generators. Both used CIRCLE timing, IMU traces and the beat detector.
- The records are simulated. Human review remains pending.

The complete archives contain per-window records, TRIAD reports and reproduction instructions.
